# StayHaven Frontend

React + Vite + Tailwind CSS frontend application for the Hotel Booking Portal.

## Features
- Hotel search and filter by location and stay dates.
- Interactive date pickers preventing past dates and invalid checkout dates.
- Real-time room availability and demand status badges ("High Demand: Only 1 room left!").
- Live Smart Stay Long-Stay discount calculation (10% off for 4+ nights).
- Responsive, modern UI styled with Tailwind CSS and Lucide React icons.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

3. **Build for production**:
   ```bash
   npm run build
   ```
